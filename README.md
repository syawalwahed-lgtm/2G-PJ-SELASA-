# Unit 7: Semangat Membara — PJ Tahun 2

Buka `index.html` dalam Chrome, Edge, Firefox atau Safari. Tiada pemasangan atau akaun diperlukan.

## Kandungan
- Nota pemanasan badan, penyejukan badan, perubahan suhu/pernafasan/kadar nadi, air dan keselamatan.
- Dua permainan pengukuhan sedia ada.
- Tepat 25 soalan objektif, empat pilihan, penerangan dan maklum balas.
- Markah /25, peratus, bintang, lencana, semakan, percubaan semula dan cetak/PDF.
- Pautan carian YouTube; guru perlu memilih dan menyemak video sebelum tayangan.

## Pemetaan kurikulum
Unit 7 “Semangat Membara”, tajuk “Mari Panaskan Badan” dan “Mari Sejukkan Badan” disenaraikan dalam salinan RPT PJ Tahun 2 yang ditemui:
- https://anyflip.com/tocev/ohbk/basic

Salinan RPT pihak ketiga, bukan hos rasmi KPM. Sahkan dengan DSKP dan RPT semasa sekolah.

## GitHub Pages
Cipta repositori, muat naik `index.html` ke root, kemudian Settings → Pages → Deploy from a branch → pilih `main` dan `/(root)` → Save. Uji URL yang GitHub paparkan selepas penerbitan selesai.
